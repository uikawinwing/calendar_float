## 删除的通用化与数据归属

删除了 Generic Profile 默认对象、多 Profile 注册表、模糊身份匹配、任意自定义身份创建、检测规则、检测结果状态、零生产调用的 hint 包装及未使用的重复 MVU 路径常量。

国家/城镇关键词、节庆主题/标签分类、颜色、备用标记、纪元与时间示例不再散落在 TypeScript 规则表中。运行时优先读取 `[fixed_event_index]` 的既有 `配置档案设置.日期/世界书/视觉`。完整配置示例仍为根目录 `节庆_索引.latest.yaml`，未另建配置条目。

为兼容没有新增字段的旧 YAML，保留集中式数据快照；不把旧固定事件或正文复制进 TypeScript，也不把整份索引注入模型。图标资产、字段协议、重复规则和持久化键继续由程序维护。主题、尺寸、过滤、排序、提醒偏好和用户标签颜色仍使用原用户设置存储，没有迁入世界书。

旧 `generic` 输入只作迁移兼容，运行身份仍为《命定之诗》；陌生显式身份拒绝整个运行索引。带高级完整逻辑的 YAML 仍需在原 YAML 中编辑，本轮没有扩充为可视化高级逻辑编辑器。

## 检查结果与既有失败

- 修改前：54/54 检查通过；修改后：`pnpm test` 60/60 通过。
- `pnpm exec eslint src/calendar-float` 通过；新增回归检查的 Node 工具引用有规则警告，无错误。
- 生产构建通过，保留原有 3 个包体积警告；使用 `TAVERN_HELPER_SKIP_SYNC=1 TAVERN_HELPER_SKIP_DUMP=1 pnpm run build`，没有启动监听或同步到宿主。
- `git diff --check` 通过。
- 完整 `pnpm exec tsc --noEmit` 仍失败。将原版源码在相同构建生成的声明下重查：47 条；重构版 45 条；新增错误 0。移除了原版缺少 `mergeManagedEntry` 导入和编辑器未使用参数两条错误。
- 剩余主要为 TypeFest/依赖声明及原有管理器未使用函数；没有为本轮重构顺手重写工具链。
- 补充业务类型检查 `pnpm exec tsc --noEmit --skipLibCheck --noUnusedLocals false --noUnusedParameters false` 通过。它跳过依赖声明和未使用项，不能替代完整检查结果。
- 全仓库 `pnpm run lint` 在原版就失败，主要来自 `tavern_sync.mjs`，不把它报告成此次新增失败。
